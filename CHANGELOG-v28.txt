Otkosy v28
- «2 плоскости» убрано из общих полей замера. Теперь оно задаётся отдельно для каждой работы: нажми на название работы в замере → «2 плоскости для этой работы» → отметь стороны (Левая / Правая / Верхняя / Нижняя).
- Удвоение считается только для отмеченных работ (м.п., цена, ведомость, PDF, Excel, рисунок замера).
- Старые замеры, где «2 плоскости» уже стояло, считаются как раньше (для всех работ), пока их не откроют и не сохранят: тогда галочки появятся у каждой работы и их можно снять там, где не нужно.
- «Взять размеры из другого окна» копирует и отметки «2 плоскости» по одноимённым работам.
